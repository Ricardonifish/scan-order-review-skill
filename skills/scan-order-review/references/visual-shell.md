# Visual: 功能骨架，不是固定皮肤

Template 提供 **可运行的点单/评价**，不是「所有店都长这样」。

## 固定的只有产品，不是版式

必须能用：菜单、规格、购物车、取餐号、排队提示、满意度分流、润色发布。  
路径保持：`index.html` · `order.html` · `compose.html` · `menu.json` · `/api/*`。

## 默认（新店 / 一键部署 / 「帮我设计」）

**重新设计界面。** 读 [design-directions.md](design-directions.md) + `/frontend-design`。  
可以拆掉黑底、圆 Logo 叠头图、白胶囊社交、2×2 Rate 白卡——这些都不是必选项。

约束：手机一列可用（宽屏可加氛围，但扫码以手机为准）；对比度够；点单和评价入口一眼能找到。

## 例外（真的只换皮）

仅当用户说「跟模板一样 / 只换色 / 只换 Logo」：

1. 黑底手机列  
2. 头图 + 圆 Logo  
3. 白胶囊社交  
4. 白底 Rate 2×2  
5. 点单 CTA + 简介

## 不要

- 每家店都做同一套 Mixue 链接页  
- 用 Next/React 另起一套产品  
- 抄竞品商标图  
- 只有桌面宽屏能看
