# Merchant needs（市场调研 → 本产品怎么接）

三轮来源：有赞桌码/取餐叫号、喜茶 GO、茶饮私域 vs 外卖佣金、碰碰贴、Chowbus 差评分流、海外 cafe QR、预约自提方案、美团团购核销（银豹/有赞）、银豹取茶进度、过敏原/自带杯菜单规范。

## Jobs → 我们怎么接

| Job | 市场做法 | 本产品 |
|-----|----------|--------|
| 高峰少排队、少听错 | 扫码+规格+取餐号 | ✅ H5 点单 + 规格 + 大号取餐号 |
| 门店码 ≠ 桌码 | 门口自提 / 桌码送餐 | ✅ 两套 URL |
| 看见还要等多久 | x杯制作中 · 预计 xx 分 | ✅ **轻量排队提示**（按未完成单估算） |
| 订单状态 | 接单→制作→待取 | ✅ 订单页可点状态（店员用手机当简易看板） |
| 预约/错峰自提 | 选时段再到店 | ⚪ 备注/材料可写「预约到店时间」；完整时段日历 = 以后加 |
| 绕开外卖佣金 | 私域小程序 | ✅ 定位：到店零抽佣演示入口 |
| 美团/点评团购核销 | POS/API 映射套餐 | ❌ 默认不做；话术：**券到吧台核销**，订单备注可写「团购」 |
| 杯贴/小票机 | 打印取餐号+规格 | ❌ 硬件不做；屏幕取餐号可给店员看/截图 |
| 过敏原 / 饮食标签 | 菜单标注 | ✅ `allergens` / `diet` 字段展示 |
| 自带杯 / 打包加价 | 选项加减价 | ✅ 用 `optionGroups` 或结算备注；材料可声明 |
| 种草+护口碑 | 👍公开 / 👎内部 | ✅ 满意度分流 + AI 润色 |
| 地推落地 | 海报+店员话术 | ✅ [floor-ops.md](floor-ops.md) |
| 商品图 | 转化率 | ⚪ `image` 可选 URL；无图用 emoji/色块 |

## 支付与团购（对商家一句说清）

- 默认：**不在线收款** → 取餐号 → 吧台出品/结账/核销团购券。  
- 美团团购真·自助核销需要官方授权+套餐映射，**超出本模板**；勿承诺「扫码自动验美团券」。  
- 以后若要线上付 / 核销，单独立项。

## Must-ship（每次交付）

1. 门店码 + 桌码 + 「扫码下单，无需排队」物料  
2. 规格 + 备注 + 堂食/外带 + 到吧台结账说明  
3. 大号取餐号；可选展示「前方约 N 单 / 预计约 M 分钟」  
4. 下单后 👍/👎 分流  
5. 售罄；过敏原若材料有则展示  
6. Handoff：[floor-ops.md](floor-ops.md) + 团购「吧台核销」说明  
7. 公开 Vercel，无登录墙
