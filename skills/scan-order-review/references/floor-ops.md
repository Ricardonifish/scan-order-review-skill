# Floor ops（贴码 + 店员话术）

没有地推，系统就是摆设（茶饮私域文章反复强调）。交付网站时**一并给**下列文案，可直接印。

## 贴码位置

| 位置 | 码类型 | 文案建议 |
|------|--------|----------|
| 门口玻璃 / 排队处 | 门店码 | **扫码下单，无需排队** |
| 收银台立牌 | 门店码 | 自提/外带扫这里 |
| 每张桌 | 桌码（带 table） | 坐着点 · 做好送到桌 / 报取餐号 |
| 外带袋贴纸（可选） | 首页或评价 | 好喝的话帮我们发条笔记 |

## 两套 URL（替换域名）

```text
门店码：https://<app>/order.html?from=qr
桌码：  https://<app>/order.html?from=qr&table=A8
短链：  https://<app>/scan?table=A8
首页：  https://<app>/
```

## 团购

美团/点评券：**到吧台出示核销**（系统不自动验券）。可在整单备注写「美团团购」。

## 店员三句话（背下来）

1. 确认体验：「今天还合口味吗？」  
2. 引导点单（排队时）：「扫这个码可以直接点，不用排队报单。」  
3. 引导评价（满意时）：「方便的话点一下写评价，文案帮你生成，发小红书/好评都行。」

不满意：**不要**推公开评价；让顾客在页上点 👎 或口头记下，店内处理。

## 老板运营提示（可选写进 handoff）

- 核心是把**已到店**客沉到自己的码上，不是和美团抢单。  
- 员工每成功引导扫码/发笔记可设小额提成（店内制度，系统不结算）。  
- 功能别堆：点单 + 取餐号 + 评价够用；会员储值以后再说。
