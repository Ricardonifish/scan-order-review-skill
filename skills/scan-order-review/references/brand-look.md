# 按材料代设计（默认）

产品 API 留在 `template/`。**视觉每次按这家店做**，不是换 CSS 变量交差。

## 何时必须重做版式

新店、一键部署、「帮我设计 / 好看一点 / 按品牌来」、给了气质/参考/Logo/门店图 —— **全部重做首页 HTML/CSS**，点单/评价页同步换字体与主色，必要时改点单页布局（分类栏、卡片、底栏）。

只有「跟模板一样 / 只换皮」才只改 `brand.css` + `assets/`。

## 流程

1. `/frontend-design`：当设计主创，给这家店一个别人认得出的身份。  
2. 从 [design-directions.md](design-directions.md) **选一个方向**（或自创），写进 brief。  
3. Brief（用户说直接做可跳过展示，但仍要在实现里遵守）：
   - 方向名 + 为何适合这家店  
   - 首屏构图（和模板不同）  
   - 4–6 hex：`pageBg` `surface` `primary` `accent` `ink` `mutedText`  
   - 展示字体 + 正文字体（不要默认又是 Outfit）  
   - 一个签名元素  
4. **重写** `index.html`、`styles.css`；更新 `brand.css` token 与 Google Fonts。  
5. Logo/头图进 `assets/`，按新构图放置（圆形不是必须）。  
6. `order.css` / `compose.css` 吃同一套 token；点单页不要仍是「绿黑喜茶仿盘」如果首页已经是纸感/灯牌/杂志。

## 上传

| 材料 | 用法 |
|------|------|
| Logo | 按新布局放，形状随设计 |
| 门店/产品图 | 可当首屏、菜单底、评价背景，加遮罩保字可读 |
| 无图 | 用 CSS/SVG 做**这家店**的图形，禁止星巴克杯、禁止无脑复用模板茶杯 |

## 禁止

- 忽略用户图和忌讳色  
- 每店同一黑底白胶囊  
- 抄竞品视觉识别  
- 换色但 i18n/页脚仍是演示店名
