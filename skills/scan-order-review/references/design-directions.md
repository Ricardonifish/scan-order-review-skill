# Design directions（每次换店必须换方向）

`template/` 里的黑底 + 圆 Logo + 白胶囊是**演示骨架**，不是品牌规范。  
新店默认：**按这家店重新设计首页 + 点单/评价页视觉**，不要复制模板构图。

先读 `/frontend-design`，再从下面选一个**最贴材料**的方向；若都不贴，自创一个并命名。  
**禁止**无理由落到这三种 AI 默认：奶油底+衬线+陶土橙；纯黑+一条荧光绿；报纸细线分栏。

## 功能必须在（位置、形状、顺序都可以变）

- 进点单：`order.html?from=qr`（桌码可带 `table=`）
- 写评价：`compose.html?platform=xiaohongshu`（及其他平台）
- 社交（材料有才做）
- 店名、营业时间/地址、可选激励文案

## 方向库（选 1，不要每店都用 A）

**A 茶室立轴** — 宣纸/米黄、竖排或偏竖标题、印章感点缀、细线。适合清茶、新中式。  
**B 夜市灯牌** — 深底但不是纯黑、霓虹边、粗无衬线、大「点单」像灯箱。适合街边奶茶。  
**C 手冲吧台** — 浅木/水泥灰、商品图优先、点单入口像手写菜单板。适合精品咖啡。  
**D 少女切页** — 浅粉/奶油、贴纸叠层、圆角照片、评价做成拍立得。适合网红果茶。  
**E 便利店灯箱** — 高对比黄红或品牌撞色、信息密、价格先出现。适合快打外带。  
**F 日式便当格** — 白底网格、细边框、分类像格子。适合简约连锁感（仍要有这家店的字/色）。  
**G 户外野餐** — 草绿+奶油、插画头图、圆按钮。适合水果茶/健康线。  
**H 杂志封面** — 一张大图占首屏 70%，店名压在图上，下方才是点单/评价。适合有门店/产品摄影。

签名元素只能有 **一个**（印章 / 灯箱字 / 手写菜单 / 叠贴纸…），其余克制。

## 执行

1. 材料 → 品类、气质、参考、图、忌讳。  
2. 选出方向名 + 4–6 hex + 2 款字体（展示+正文，避免又是 Outfit-only）。  
3. 用 ASCII 画一屏首页线框（和模板不同）。  
4. **重写** `index.html` + `styles.css`（可以整页换 class，不必保留 `.hero`/`.social` 结构）。  
5. `brand.css` 只放 token；`order.css` / `compose.css` 跟同一套主色/字体，但点单页也可以改排版密度，不必像首页复制。  
6. 用户说「跟模板一样 / 只换皮」才保留 Mixue 壳。

## 自检（做完问自己）

若把店名换成另一家奶茶，版式是否几乎不变？若是，重做构图，不要只改 hex。
