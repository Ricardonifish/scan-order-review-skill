# Roadmap（点名再做）

| 能力 | 为何商家要 | 现状 |
|------|------------|------|
| 微信/支付宝收款 | 少一次吧台收银 | 未做 |
| 预约取餐时段 | 写字楼错峰 | 仅备注；无日历 |
| 取餐订阅消息/短信 | 做好了再来 | 未做 |
| 杯贴/网口打印 | 吧台凭贴做茶 | 未做；用大号取餐号代替 |
| 美团/点评/抖音验券 | 少漏核错核 | **不做假对接**；话术吧台核销 |
| 会员储值/积分 | 锁客 | 未做 |
| KDS / 叫号大屏 | 高峰减催单 | 订单页状态 = 极简版 |
| 多门店选店 | 连锁 | 单店模板 |
| 外卖运力 | 自营外送 | 仅外链美团可选 |

Skill 默认：**先把 must-ship 跑通**，上表功能用户明确要求再加，并改 handoff 话术。
