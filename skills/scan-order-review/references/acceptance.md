# Acceptance checklist（店主 / 部署后）

对照茶饮门店真实动线：贴码 → 点单 → 取餐号 → 满意度分流 →（可选）发笔记。

## 首页

- [ ] 生产 URL 样式正常；店名/Logo 无旧品牌残留
- [ ] 首页**不像**未改的模板壳（黑底三胶囊）；能说出用了哪个设计方向
- [ ] 营业时间/地址/社交可读；激励文案若有则清晰

## 双码 + 地推

- [ ] 门店码 `…/order.html?from=qr`
- [ ] 桌码 `…/order.html?from=qr&table=A8`（页眉有桌号）
- [ ] 已打印/张贴：[floor-ops.md](floor-ops.md) 文案（门口「扫码下单，无需排队」）
- [ ] 店员会说三句话

## 点单

- [ ] 规格 + 备注；**堂食/外带**可切换
- [ ] 提示为到吧台取餐/结账（未假装已在线付款）
- [ ] 菜单上方有排队/等待提示（可关）
- [ ] 订单页店员可点状态：接单→制作→请取餐
- [ ] 团购话术清楚：券到吧台核销，非系统自动验

## 评价分流

- [ ] 下单成功先问满不满意
- [ ] 满意 → 写评价 / 小红书润色
- [ ] 不满意 → 内部反馈，**不**打开公开平台
- [ ] 差评草稿润色不会洗成安利

## 环境

- [ ] Vercel Authentication 关；Key 未进 Git
